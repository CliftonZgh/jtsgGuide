# 伤者问题总览

发生交通事故后，伤者处理问题可以按“先救治、再固定证据、后核算赔偿”的顺序推进。

## 第一阶段：优先救治

- 及时就医，向医院完整说明事故经过和受伤部位
- 保存挂号、病历、检查报告、诊断证明和费用明细
- 伤情紧急时，向交警和保险公司咨询交强险垫付
- 肇事逃逸、无保险或费用无着落时，咨询道路交通事故社会救助基金

## 第二阶段：固定证据

- 保存事故认定书、现场照片和视频
- 记录目击者联系方式与道路监控线索
- 保存医疗原始票据及复印件交接记录
- 通过劳动合同、工资流水等材料证明误工损失
- 需要护理或营养时，请医院在诊断证明或医嘱中明确记载

## 第三阶段：评估损失

根据伤情和治疗进展，整理医疗费、误工费、护理费、营养费、交通费、后续治疗费和可能的伤残赔偿项目。治疗尚未稳定、鉴定尚未完成时，不要急于签署一次性结清协议。

## 第四阶段：协商或维权

先与保险公司和责任方协商；协商不成时，可以申请调解或咨询律师，通过诉讼主张合理赔偿。注意保留所有书面沟通和材料提交记录。

!!! note "提示"
赔偿项目、鉴定时间和救助基金规则可能因地区和案件情况不同，请以当地规定为准。
