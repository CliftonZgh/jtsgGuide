# 跟踪处置：通用流程

本页适用于所有事故当事人，用于了解现场离开后的共同处理节点。具体责任和赔偿仍要结合事故认定、保险合同及当地规定判断。

## 处理顺序

1. 报警并取得报警记录或案件编号
2. 向保险公司报案并确认理赔联系人
3. 等待或领取交通事故责任认定材料
4. 完成车辆查勘、定损和维修
5. 整理医疗、维修及其他损失凭证
6. 协商、调解或依法处理赔偿争议
7. 确认付款和材料归档后结案

## 重要材料

- 事故认定书或快速处理凭证
- 报案号、案件号和保险联系方式
- 现场照片、视频和证人信息
- 维修定损单、维修清单和发票
- 病历、诊断证明、医疗票据和费用明细
- 赔偿协议、转账记录和重要沟通记录

## 共同注意事项

- 重要沟通尽量使用文字并保留记录
- 不删除原始视频，不伪造或篡改证据
- 不在损失未明确时急于私了
- 不向陌生账户支付无法核验的费用
- 对交警、保险公司或对方提出的材料要求逐项核对

## 需要专业帮助的情况

有人身伤亡、责任争议、逃逸、酒驾、无证驾驶、重大财产损失或赔偿金额较大时，建议及时咨询交警、保险公司、律师或法律援助机构。
