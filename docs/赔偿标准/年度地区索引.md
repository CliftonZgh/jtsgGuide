本页是年度地区索引。每个年度单独使用一个 Markdown 页面，年度页面内再按省、市、自治区列出城市速查页，后续可以逐项添加经过核验的标准。

## 统一记录字段

每个城市页面统一记录以下内容，便于横向查询和后续维护：

- 适用年度、地区和事故发生时间
- 赔偿项目、计算单位和具体金额
- 适用条件及是否存在过渡规则
- 正式文件名称、文件编号、发布日期和生效日期
- 官方来源链接和最后核验日期

!!! warning "使用边界"
    赔偿限额、统计口径和地方办理要求可能调整。涉及具体金额时，应以事故发生地现行规定、保险合同、交警或法院要求为准。本页不构成法律意见。
