# 报警与报险

## 何时报警

以下场景建议第一时间拨打 122 或 110：

- 有人员伤亡
- 当事人拒绝配合
- 责任争议明显
- 涉嫌酒驾、逃逸、无证驾驶

## 报警沟通模板

可按“4 要素”描述：

1. 我是谁（姓名+联系方式）
2. 在哪里（道路+方向+地标）
3. 发生什么（车辆数量+是否受伤）
4. 需要什么（请求交警到场处理）

## 何时报险

建议在事故后尽快联系保险公司，通常越早越好。

报险时准备信息：

- 保单号或车牌号
- 事故时间地点
- 事故简述与现场照片
- 对方车辆与联系方式

## 沟通注意

- 事实描述为主，不做情绪化表达
- 不承诺“私了后不追责”等难以履行内容
- 涉及人伤时，不轻易预估赔偿金额
