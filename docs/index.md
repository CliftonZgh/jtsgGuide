# 交通事故处理指南

> 目标：帮助你在事故发生后的前 30 分钟内，完成最关键的取证、沟通与报案动作。

## 先记住三句话

1. **先保安全，再谈责任。**
2. **先固定证据，再挪车离场。**
3. **先按流程报案，再协商赔偿。**

## 适用范围

- 机动车与机动车事故
- 机动车与非机动车/行人事故
- 轻微事故快速处理
- 有人员受伤或争议较大的事故

## 推荐阅读路径

- 第一步：阅读“现场处置总览”了解黄金时间动作
- 第二步：阅读“报警与报险”掌握电话沟通模板
- 第三步：阅读“责任认定”与“保险理赔”避免流程踩坑

## 紧急提示

!!! warning "出现以下任一情形，优先报警并等待交警" - 有人员伤亡或疑似受伤 - 驾驶人疑似酒驾、毒驾、无证驾驶 - 车辆无法移动或阻断交通 - 当事人拒绝配合、身份信息不明

## 免责声明

本指南为通用信息参考，不构成法律意见。各地交管与保险细则可能存在差异，请以事故发生地交警和保险公司要求为准。
